How a Project Works

  1. You send a project request using the application form.
  2. We agree on the pages, content, and timeline.
  3. I build the structure and share a first version.
  4. You review it and I make the agreed revisions.
  5. The website is published and handed over.

Important: please send only the information needed for the project. Never send passwords or private documents in a request.
