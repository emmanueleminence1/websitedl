My Story

I am a web developer who enjoys turning ideas into working websites. I have built a restaurant website and a real estate listings website, and I am now strengthening my foundations by building pages with semantic HTML alone.

Good websites start with good structure. When the headings, lists, links, and forms are correct, a page works for everyone: people using phones, keyboards, and screen readers, as well as search engines.

Skills

  • HTML: semantic structure, forms, tables, and accessibility
  • CSS and Tailwind CSS: responsive layouts
  • JavaScript, TypeScript, and React
  • Node.js and Vite for building projects
  • Git and GitHub for version control
  • Netlify and GitHub Pages for publishing

How I Plan a Website

  1. Listen to the goals of the owner and the needs of visitors.
  2. Plan the pages, headings, and content.
  3. Write the structure in meaningful HTML.
  4. Add design and behaviour.
  5. Test on different screens and with the keyboard only.
  6. Publish the site and keep it updated.

Web Terms I Use

Semantic HTML
Using elements for their meaning, such as nav for navigation and main for the main content.
Accessibility
Building pages that people with different abilities and devices can use.
Alternative text
A short written description of an image for people who cannot see it.
Responsive design
Layouts that adapt to the width of the screen, from phones to desktops.
